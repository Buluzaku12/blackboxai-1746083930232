# Virtual Photobooth

## Project Overview
Virtual Photobooth is a web application that allows users to take photos using their device's camera, upload images, add funny texts, and download the final photo along with customizable frame templates. This interactive application provides a user-friendly interface to create memorable snapshots.

## Installation
To get started with Virtual Photobooth, clone this repository to your local machine and open the `index.html` file in your preferred web browser.

```bash
git clone https://github.com/yourusername/virtual-photobooth.git
cd virtual-photobooth
open index.html  # or use your browser to open the file
```

## Usage
1. Open the application in your web browser.
2. Allow access to your camera when prompted.
3. Capture a photo by clicking the "Ambil Foto" button.
4. Optionally, upload an image by clicking the "Upload Foto" button and selecting an image file from your device.
5. Add funny text in the input field below the camera view.
6. Choose a frame template from the selection on the right.
7. Once you're satisfied with the photo and text, click the "Download" button to save it.

## Features
- **Camera Access**: Use your device's camera to take photos directly from the app.
- **Photo Uploading**: Upload images from your device to enhance your creations.
- **Text Input**: Add custom text to your photos for personalization.
- **Dynamic Frame Selection**: Choose from various frame templates to decorate your photos.
- **Download Option**: Save your edited photos to your device.

## Dependencies
The project relies on the following external libraries:
- [Tailwind CSS](https://tailwindcss.com/) for styling.
- [Font Awesome](https://fontawesome.com/) for icons.
